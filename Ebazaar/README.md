# Ebazaar – Bangladesh Online Marketplace (Demo)

**App name:** Ebazaar (with 🛍️ logo)

Login is by **phone number + password**.

## How to run

1. Unzip the folder.
2. Open `index.html` in Chrome / Firefox / Edge.
3. No server needed – data is in browser localStorage.

## Features (as instructed)

- First screen: Merchant or Customer
- Merchant: demo ৳100 lock → unlock 1 month → shop setup → products with photos → orders with customer details → mark supplied → sales table + profit + graph
- Customer: profile (name, phone, address, area — no shop name), search bar, product photos, multi-shop results sorted by higher rating then nearer location, place order, rate shops
- Orders connected: customer order appears for the merchant immediately
- Demo shops, products, and photos included

## Reset data

DevTools → Application → Local Storage → delete `ebazaar_v1` → refresh.
